# Licence of the Comparative Agendas Project data

The Comparative Agendas Project (CAP) distributes its topic codes and other project variables under the
[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International licence (CC BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/)
(https://www.comparativeagendas.net/pages/Copyright-and-Legal, accessed 30 October 2026). Any re-use must
follow that licence and cite the datasets as CAP's [How to Cite](https://www.comparativeagendas.net/pages/How-to-cite)
page asks.

## What this covers

Every file in this repository that carries CAP texts or CAP topic codes is under CC BY-NC-SA 4.0, not under
the repository's CC BY 4.0:

- `data/comparative_agendas_project/`: the raw CAP files, codebooks and the train, validation and test splits;
- `data/policy_<LANG>_cycle_<N>/`: model predictions on the CAP test splits, which repeat the test texts;
- `data/sust_finance/` and `data/sust_finance_EN_cycle_<N>/`: built from the UK CAP acts of parliament;
- `data/technology/` and `data/technology_EN_cycle_<N>/`: built from the UK CAP acts of parliament.

The code that builds and scores these files stays under the MIT licence.
